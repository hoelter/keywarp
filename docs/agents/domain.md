# Domain Docs

Single-context repo, with domain docs under `docs/` rather than the repo root:

- **`docs/GLOSSARY.md`**: the domain vocabulary. Use its terms in code, tests, issues and docs, and avoid the synonyms it lists under _Avoid_.
- **`docs/adr/`**: architecture decision records, created when the first decision needs one.

If either doesn't exist, proceed silently.
